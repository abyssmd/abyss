# Abyss

This is where to report bugs and suggest features for [Abyss](https://abyss.md), the Markdown editor for Mac, iPhone and iPad.

- Get Abyss for Mac at [abyss.md](https://abyss.md)
- Get Abyss Writer for iPhone and iPad on the [App Store](https://apps.apple.com/app/id6820560837)

## Reporting a bug

[Open a bug report](../../issues/new?template=bug_report.yml) and say which device and version you're on. Steps to reproduce and a screenshot help a lot.

## Suggesting a feature

[Open a feature request](../../issues/new?template=feature_request.yml) and tell us how you'd use it.

Please search the existing issues first, in case someone has already asked.

The source code for Abyss isn't in this repository.
